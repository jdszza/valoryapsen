# ── Quais serviços sobem ─────────────────────────────────────────────────────

# sem ela o compose sobe 7 serviços (mysql, central, vision-adapter,

# adapters seriais nem os simuladores de dispenser, CNC e balança.
#
# É o que faz a porta 8103 ficar livre para o weight-adapter do host: com
# `COMPOSE_PROFILES=simulado`, o weight-adapter de container subiria e
# publicaria a mesma porta, e quem chegasse primeiro ficaria com ela.
#
# COMPOSE_PROFILES=simulado

# Balança física fora de serviço: `balanca-simulada` sobe SÓ o weight-adapter e

# ── Onde o central procura cada adapter ──────────────────────────────────────

# A balança é a única que já tem firmware: o adapter dela roda no HOST, fora do

# Comentado enquanto a balança é simulada: o default do compose
# (http://weight-adapter:8103) aponta para o adapter de container.
# WEIGHT_ADAPTER_URL=http://host.docker.internal:8103

# Descomente cada linha no dia em que a placa correspondente entrar. Enquanto
